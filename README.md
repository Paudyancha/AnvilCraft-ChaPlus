## 物品介绍

### 1.钢叉
钢叉,灵感来源于刺猹的钢叉.\
合成方式:
- `无粒无`
- `无钢粒`
- `铁无无`
铁:铁锭 钢:皇家钢 粒:铁粒
功能:
- 右键时 钢叉蓄力,若副手为方块则进行调谐,消耗一个物品,松开后抛出.若击中生物则生成一个假玩家对这实体使用该方块.丢弃假玩家手上的方块.
- 左键时 空副手潜行取消调谐返还方块.否则进行共振挖掘.
二叉戟
### 2.打印仓
打印仓,灵感来源为oni中的打印仓.\
约束仓砸入磁电核心后获得.\
可存储四种砧子个一个,可打印食物,生物.\
打印生物需要琥珀块或者头颅,打印食物需要对应食物.
### 3.猹砧
猹砧,其他附属也有就加了.\
合成方式:
```
棕棕棕
空灰空
灰灰灰
```
羊毛合成,应该跟獐一样棕色灰黄色.\
功能:\
砸到西瓜后与之一同消失.
